# my dotfiles

## Notes 

This repository is designed exclusively for macOS and contains my favorite tools, applications, and CLI utilities.

## Installation

1. Run this command
```bash
xcode-select --install
```

2. Download the repository
```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/D3ller/dotfiles/HEAD/scripts/setup.sh)"
```

3. Restart your terminal
```bash
exec zsh -l
```
